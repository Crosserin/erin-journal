## 📖 What this is

One file per day. Markdown. Committed.

- ❌ No streak counter
- ❌ No engagement optimization
- ❌ No analytics dashboard guilting me for missing a Tuesday
- ❌ No pricing page
- ❌ No onboarding flow
- ❌ No "here's your yearly wrap-up 🎉"

Just a place to put the weight of a day before it slips into the desert.

Commit from phone or laptop. Read it six months later and remember what last spring actually felt like.

## 🏛️ Structure

```
erin-journal-data/
├── 2026/
│   ├── 01/
│   │   ├── 2026-01-01.md
│   │   └── 2026-01-02.md
│   └── 02/
│       └── 2026-02-14.md
└── README.md
```

One file per day. `YYYY/MM/YYYY-MM-DD.md`. That's the **entire schema**.
